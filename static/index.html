Sensair

Air quality sensor for CO2, temperature, humidity and VOC. Install the firmware right here in your browser and connect it to your WiFi and Home Assistant.

Your browser cannot talk to USB devices. Please open this page in Google Chrome or Microsoft Edge on a computer (Windows, macOS or Linux). Phones and tablets are not supported.
This page has to be opened over https:// to access USB devices.

What you need

  • Your Sensair
  • A USB-C cable that can transfer data (some cables only charge)
  • A computer with Google Chrome or Microsoft Edge
  • The name and password of your WiFi (2.4 GHz)

Step by step

  1. Connect the Sensair to your computer with the USB cable.
  2. Click Install Sensair and select the device in the list. It is usually called USB JTAG/serial debug unit.
  3. Confirm the installation. This takes about one minute; do not unplug the cable.
  4. Enter your WiFi name and password when asked.
  5. Open Home Assistant. Under Settings > Devices & services the Sensair shows up as a newly discovered device. Click Add. Home Assistant then secures the connection automatically.
  6. Optional: on the device page under Configuration, set your altitude, a temperature offset and the hours when the display turns off at night.

You can now unplug the Sensair from the computer and use any USB power supply.

Troubleshooting

The device does not appear in the list

Try another USB cable, as many cables only charge. If it still does not show up, hold the BOOT button on the board while plugging in the cable, then try again.

No Chrome or Edge? Use the Windows installer

Download the Windows installer, unzip it and double-click Install-Sensair.cmd. It does the same as this page: it installs the firmware and asks for your WiFi.

Setting up WiFi without a computer

Within 15 minutes after power-up the Sensair opens its own WiFi network Sensair Setup. Connect to it with your phone; a page to enter your WiFi opens automatically (otherwise go to http://192.168.4.1). The Home Assistant app can also set up the WiFi via Bluetooth.

Setup does not work anymore

For security, the setup is only possible within 15 minutes after the Sensair is powered up. Unplug it for a few seconds and plug it back in, then try again.

Home Assistant does not find the Sensair

Make sure the Sensair and Home Assistant are in the same network. You can also add it manually: Settings > Devices & services > Add integration > ESPHome.
